# 📦 Parcel Delivery Web Application - Frontend

Fast. Reliable. Delivered.  
The frontend for a full-stack parcel delivery system built with React, Redux, and Tailwind CSS—designed to simplify logistics across Bangladesh.

---

## 🌐 Live URL

- **Frontend**: [https://l2-assignment-006.vercel.app](https://l2-assignment-006.vercel.app)

---

## 🚀 Overview

This frontend application allows users to:
- Register and log in securely
- Create and manage parcel deliveries
- Track parcel status in real time
- Make payments via SSLCommerz
- View delivery logs and performance insights

Built with modern React practices and optimized for Bengali users, the platform supports both admin and customer workflows.

## 🛠️ Tech Stack

### Core
- **React 19** → UI library for building component-based interfaces
- **Redux Toolkit** (v2.9.0) → State management for authentication, parcel tracking, and real-time updates
- **React Redux** (v9.2.0) → Official React bindings for Redux
- **TypeScript** (v5.8.3) → Type-safe JavaScript
- **Vite** (v7.1.6) → Fast build tool and development server

### UI & Styling
- **Tailwind CSS** (v4.1.13) → Utility-first CSS framework
- **Radix UI** (@radix-ui/* packages) → Accessible component primitives
- **ShadCN UI** (via Radix + class-variance-authority) → Reusable component library
- **Lucide React** (v0.544.0) → Consistent icon set
- **React Icons** (v5.5.0) → Additional icon options
- **Sonner** (v2.0.7) → Toast notifications
- **tw-animate-css** (v1.3.8) → Animation utilities

### Forms & Validation
- **React Hook Form** (v7.63.0) → Performant form handling
- **Zod** (v4.1.11) → Schema validation
- **@hookform/resolvers** (v5.2.2) → Zod integration with React Hook Form

### Routing & Data Fetching
- **React Router** (v7.9.1) → Client-side routing
- **Axios** (v1.12.2) → HTTP client for API requests
- **@tanstack/react-table** (v8.21.3) → Powerful table utilities

### Additional Libraries
- **input-otp** (v1.4.2) → OTP input for receiver verification
- **react-responsive-carousel** (v3.2.23) → Image carousels
- **clsx** (v2.1.1) + **tailwind-merge** (v3.3.1) → Conditional class management
- **class-variance-authority** (v0.7.1) → Variant-based styling
